# network-task-manager

This client-server application is being created for task allocation between users of specific groups.

Client and server are run in different projects.

Enter 'help' in the command line to see all commands of this project.

The commands for working with a task are run after selecting the task via the 'select\_task' command from the accessed list.

All commands except 'help', 'exit', 'register' and 'login' you can run after login only.
